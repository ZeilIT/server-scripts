# server-scripts

Скрипты для автоматического обновления сервера.

## update.sh

Основной скрипт. Проверяет и устанавливает обновления пакетов, удаляет устаревшие пакеты, ведёт детальный лог по дням.

## runner.sh

Обёртка для cron. Подтягивает свежую версию скриптов из репозитория и запускает `update.sh`.
